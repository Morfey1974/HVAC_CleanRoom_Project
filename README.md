# HVAC CleanRoom Project

Распределенная система управления климатом (HVAC) для чистых помещений.

## Архитектура системы
Проект построен по модульной распределенной архитектуре, объединенной по локальной шине CAN:
*   **Главный ПЛК (STM32H7):** Центральный узел системы, агрегирующий данные со всех подсетей, реализующий алгоритмы ПИД-регулирования и обеспечивающий связь с HMI верхнего уровня (Ethernet / Modbus TCP) и сторонними системами дверей (RS485).
*   **Локомотивы (Концентраторы):** Подконтроллеры, управляющие локальными сцепками (группами Вагонов) и собирающие с них данные для передачи Главному ПЛК.
*   **Вагоны (Модули Ввода/Вывода):** Оконечные устройства на базе STM32F042F6Px. Включают Аналоговые (АЦП ADS1220) и Дискретные модули. Общаются с Локомотивом по изолированной шине CAN.

## Структура репозитория (Monorepo)
*   `Docs/` - Документация, схемы, ТЗ и планы проекта.
*   `Shared_Libs/` - Общие библиотеки (например, `can_protocol.h`).
*   `Firmware_Wagons/` - Прошивки модулей ввода/вывода (Analog_Modul_AI, Analog_Modul_AO, Digital_Modul_DI, Digital_Modul_DO).
*   `Firmware_Locomotive/` - Прошивка концентратора.
*   `Firmware_MainPLC/` - Прошивка Главного ПЛК.
*   `Firmware_Displays/` - Прошивки панелей оператора (TFT5 SSD1963).
*   `Web_Interface/` - Файлы фронтенда/бэкенда.

## Особенности
*   Удаленное обновление прошивок Вагонов и Локомотивов через Custom CAN Bootloader.
*   Аппаратная изоляция CAN-шины (ISO1050).
*   Проекты организованы для STM32CubeIDE в формате иерархического монорепозитория.
