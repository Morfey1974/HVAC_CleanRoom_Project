# Структура проекта HVAC

Соблюдай следующую иерархию папок:
- `Firmware_MainPLC` — главный контроллер (ПЛК).
- `Firmware_Locomotive` — головной блок управления.
- `Firmware_Wagons` — модули и периферия (например, датчики).
- `Firmware_Displays` — экраны (панели оператора).
- `Shared_Libs` — общие библиотеки.
- `Web_Interface` — веб-часть.
- `Docs` — документация.

Строго размещай изменения только в нужной папке.
