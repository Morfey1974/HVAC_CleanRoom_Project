# Плата HMI 10" — железо, CubeMX, распиновка

Решение 2026-10-22 по даташиту EastRising **ER-TFTM101-1** (`Docs/Display TFT10.1/ER-TFTM101-1_Datasheet.pdf`) и проекту `Firmware_Displays/Display_TFT10.1_HMI`.

Шина экрана в CubeMX уже стоит в файле `STM32H723ZGT6 with TFT10.1 LT7683.ioc` (та же раскладка, что у дисплея 4.3"). Ниже — что это значит, что ещё добавить и куда паять.

---

## 1. Что за дисплей и как его настраиваем

Модуль **не** «голая» RGB-матрица. На его плате уже есть контроллер **LT7683** (в даташите также RA8876 — это тот же класс, команды совместимы), своя память кадра, подсветка и ёмкостный сенсор.

Следствия для нашей платы:

| Было в ТЗ (черновик) | Как делаем |
|---|---|
| LTDC + внешняя SDRAM под кадр | Не нужно. Кадр держит LT7683 |
| TouchGFX рисует в RGB-шину | Не нужно. Конфигуратор отдаёт пакет картинок/шрифтов; прошивка HMI рисует через 2D-движок LT7683 (как SSD1963 на 4.3") |
| Сенсор отдельной шиной | Сенсор выведен на тот же 40-контактный разъём JP1/CON1 |
| Связь с ПЛК по CAN | Нет. Только Ethernet через DIN-коммутатор |

**Как настраивается HMI в системе**

1. Инженер в Конфигураторе собирает экраны (комнаты, установка, аварии, уставки) из библиотеки элементов.
2. При выгрузке в ПЛК собирается **пакет HMI**: экраны, подписи на ru/en/he, привязки сигналов, картинки.
3. ПЛК по Ethernet отдаёт пакет плате HMI. Плата кладёт его в свою флеш (OCTOSPI, как у ПЛК).
4. В работе HMI сама подписывается у ПЛК на живые значения и аварии. Сервер приложения не обязателен.
5. Касание: **GT9271** на модуле → I2C → STM32. Уставки и квитирование уходят в ПЛК после PIN-кода роли.
6. Язык выбирается на панели. Иврит — справа налево зеркалится только текст, не схема установки.
7. Картинку на экране нельзя держать без изменений часами (выгорание TFT). На простое — тёмный заставка через 5–10 мин.

Микроконтроллер платы: **STM32H723ZGT6**, корпус LQFP144. Питание логики 3.3 В. Дисплейный модуль питаем **5 В**.

На плате модуля по фото 2026-10-22: чип **LEVETOP LT7683**, сенсор **GT9271** (U8, шлейф: 1 RST, 2 SDA, 3 SCL, 4 INT, 5 VDD, 6 GND), стабилизатор **AMS1117-3.3** (U2) — логика модуля 3.3 В из входных 5 В.

## 2. Перемычки на модуле ER-TFTM101-1

Сверка с даташитом §4.5 и платой (2026-10-22). «Замкнута» = резистор 0 Ом или капля припоя.

Сенсор на этой плате **ёмкостный GT9271** — это не перемычки, а отдельный чип. Перемычки J1–J14 задают только шину к LT7683.

Сейчас на плате полный режим **4-wire SPI**: замкнуты J2, J4, J6–J10, J21–J24; разомкнуты J1, J3, J5, J11–J14. Для нашей платы нужен **8080 16 бит** — иначе FMC не заработает. Подсветка с нашей ноги: J27 замкнута, J28 разомкнута — так и оставить. Питание 5 В: J25 разомкнута — так и оставить.

| Перемычка | Сейчас | Нужно 8080 | Что сделать |
|---|---|---|---|
| J1 | разомкнута | замкнута | **поставить 0 Ом** |
| J2 | замкнута | замкнута | не трогать |
| J3 | разомкнута | замкнута | **поставить 0 Ом** |
| J4 | замкнута | разомкнута | **снять 0 Ом** |
| J5 | разомкнута | разомкнута | не трогать |
| J6 | замкнута | разомкнута | **снять 0 Ом** |
| J7 | замкнута | разомкнута | **снять 0 Ом** |
| J8 | замкнута | разомкнута | **снять 0 Ом** |
| J9 | замкнута | разомкнута | **снять 0 Ом** |
| J10 | замкнута | разомкнута | **снять 0 Ом** |
| J11, J12, J13, J14 | разомкнуты | замкнуты | **поставить 0 Ом на все четыре** (верхние 8 бит шины) |
| J15…J20, J25, J26 | разомкнуты | разомкнуты | не паять |
| J21, J22, J23, J24 | замкнуты | разомкнуты | **снять 0 Ом** |
| J27 | замкнута | замкнута | не трогать |
| J28 | разомкнута | разомкнута | не трогать |

Не разводить: JP2 (карта), JP3 (I2C/PWM модуля), JP4 (загрузка флеш модуля). Контакт 12 модуля (NC) — никуда не вести.

## 3. CubeMX — пошагово

Открыть: `Firmware_Displays/Display_TFT10.1_HMI/Application/STM32H723ZGT6 with TFT10.1 LT7683.ioc`.

Чип: **STM32H723ZGTx**, корпус **LQFP144**.

### 3.1 Шина экрана FMC (уже включена — сверить, не ломать)

**Pinout & Configuration → Connectivity → FMC**

- Mode: **NOR Flash / PSRAM / SRAM / ROM**
- NOR/PSRAM 1:
  - Chip Select: **NE1**
  - Data: **16 bits**
  - Address: только **A0** (это RS: команда / данные)

**FMC Configuration (правая панель, вкладка Configuration):**

| Поле | Значение |
|---|---|
| Memory type | SRAM |
| Data width | 16 bits |
| Write operation | Enabled |
| Address setup time | 3 |
| Data setup time | 10 |
| Bus turnaround | 3 |
| Wait signal | Disable (пока не отладим WAIT) |
| Extended mode | Disable |

**System Core → CORTEX_M7 → MPU:** регион с базы `0x60000000`, размер 64 B, Full access, Bufferable, Execute never. Это банк NE1: команда по адресу `0x60000000`, данные по `0x60000002`.

На схеме пинов FMC должны быть ровно такие ноги (уже расставлены, как у 4.3"):

| Сигнал CubeMX | Нога STM32 | Метка |
|---|---|---|
| FMC_D0 | PD14 | LCD_D0 |
| FMC_D1 | PD15 | LCD_D1 |
| FMC_D2 | PD0 | LCD_D2 |
| FMC_D3 | PD1 | LCD_D3 |
| FMC_D4 | PE7 | LCD_D4 |
| FMC_D5 | PE8 | LCD_D5 |
| FMC_D6 | PE9 | LCD_D6 |
| FMC_D7 | PE10 | LCD_D7 |
| FMC_D8 | PA4 | LCD_D8 |
| FMC_D9 | PA5 | LCD_D9 |
| FMC_D10 | PE13 | LCD_D10 |
| FMC_D11 | PE14 | LCD_D11 |
| FMC_D12 | PC0 | LCD_D12 |
| FMC_D13 | PD8 | LCD_D13 |
| FMC_D14 | PD9 | LCD_D14 |
| FMC_D15 | PD10 | LCD_D15 |
| FMC_A0 | PF0 | LCD_RS |
| FMC_NOE | PD4 | LCD_RD |
| FMC_NWE | PD5 | LCD_WR |
| FMC_NE1 | PC7 | LCD_CS |

Если нога жёлтая — клик по ней на картинке чипа и выбрать этот сигнал (не другую альтернативу).

Скорость FMC-ног: **Very High**, без подтяжки.

### 3.2 Ноги сброса и подсветки (уже есть)

**Pinout** — клик по ноге, **GPIO_Output**:

| Нога | User Label | GPIO output level | Mode | Pull | Speed |
|---|---|---|---|---|---|
| PG0 | `LCD_REST` | High | Output Push Pull | No pull | Low |
| PG1 | `LCD_LED` | High | Output Push Pull | No pull | Low |

`LCD_REST` — сброс модуля, активный низкий: при старте держать низко ≥ 1 мс, потом высоко и ждать готовности (в даташите: ≥ 256 тактов OSC, затем проверка регистра статуса).
`LCD_LED` — BL_CONTROL, высокий = подсветка включена.

### 3.3 Добавить сейчас: WAIT, INT контроллера, сенсор I2C

Этого в ioc ещё нет.

**WAIT и INT LT7683**

| Нога | Клик в Pinout | User Label | Mode | Pull | NVIC |
|---|---|---|---|---|---|
| PD6 | GPIO_Input | `LCD_WAIT` | Input | Pull-up | нет |
| PE0 | GPIO_EXTI0 | `LCD_INT` | External Interrupt Mode with Falling edge | Pull-up | System Core → NVIC → **EXTI line0 interrupt** = Enabled |

WAIT низкий = контроллер занят. На первом включении можно не использовать (тайминги FMC уже спокойные). INT — прерывание LT7683 (касание через контроллер не сюда, см. CTP_INT).

**Сенсор — Connectivity → I2C1**

- Mode: **I2C**
- Configuration:
  - Speed: **Fast Mode** (400 кГц)
  - Clock No Stretch Mode: Disabled
  - Address: 7-bit, наш чип — master. **GT9271**: адрес `0x5D` (если INT высокий в момент сброса) или `0x14` (если INT низкий). Для этой панели держим `0x5D`. Скорость не выше 400 кГц.

На картинке чипа:

| Нога | Сигнал | User Label |
|---|---|---|
| PB8 | I2C1_SCL | `CTP_SCL` |
| PB9 | I2C1_SDA | `CTP_SDA` |

У обеих: Open Drain, Pull-up (плюс внешние 4.7 кОм к 3.3 В на плате, если на модуле нет своих).

**GPIO сенсора**

| Нога | Клик в Pinout | User Label | Mode | Pull | GPIO output level | NVIC |
|---|---|---|---|---|---|---|
| PB6 | GPIO_EXTI6 | `CTP_INT` | Rising edge | Pull-up | — | **EXTI line[9:5] interrupt** = Enabled |
| PB7 | GPIO_Output | `CTP_RST` | Output Push Pull | No pull | High | нет |

Ноги RST и INT на своей плате обязательны: при старте прошивка коротко держит RST низко, INT высоко — так GT9271 садится на адрес `0x5D`, затем INT снова вход. В CubeMX INT сразу как EXTI; смена на выход — только в своей части прошивки на время сброса.

### 3.4 Что не включать под экран

- **LTDC** — нет.
- **SDRAM / FMC SDRAM** — нет.
- **SPI** на ноги экрана — нет (параллель 8080, не SPI).
- **FDCAN** для работы HMI не нужен. В текущем ioc FDCAN1 сидит на PA11/PA12 — это ноги USB. На своей плате FDCAN1 выключить и отдать PA11/PA12 под USB (как на ПЛК).

### 3.5 Своя плата (не Nucleo) — сеть, USB, флеш пакета

Ставить после того, как картинка на модуле завелась. Раскладка как у Главного ПЛК, кроме сброса PHY (PC0 занят шиной экрана).

**Connectivity → ETH**

- Mode: **RMII**
- PHY: LAN8742
- Middleware: **LwIP** (как на ПЛК)

| Сигнал | Нога | User Label |
|---|---|---|
| ETH_REF_CLK | PA1 | RMII_REF_CLK |
| ETH_MDIO | PA2 | RMII_MDIO |
| ETH_CRS_DV | PA7 | RMII_CRS_DV |
| ETH_MDC | PC1 | RMII_MDC |
| ETH_RXD0 | PC4 | RMII_RXD0 |
| ETH_RXD1 | PC5 | RMII_RXD1 |
| ETH_TX_EN | PG11 | RMII_TX_EN |
| ETH_TXD0 | PG13 | RMII_TXD0 |
| ETH_TXD1 | PB13 | RMII_TXD1 |
| GPIO_Output | **PC2** | ETH_NRST |

Скорость RMII-ног: Very High. Кварц 25 МГц на PHY, REF_CLK 50 МГц с PHY на PA1. HSE МК тоже 25 МГц (как ПЛК), не 8 МГц от Nucleo.

**Connectivity → USB_OTG_HS**

- Mode: **Device_Only FS**
- Middleware: USB_DEVICE, класс **CDC** (виртуальный COM для IP и аварии)

| Сигнал | Нога |
|---|---|
| USB_OTG_HS_DM | PA11 |
| USB_OTG_HS_DP | PA12 |

**Connectivity → OCTOSPI1** (флеш пакета HMI, как W25Q на ПЛК)

| Сигнал | Нога |
|---|---|
| OCTOSPIM_P1_CLK | PF10 |
| OCTOSPIM_P1_NCS | PE11 |
| OCTOSPIM_P1_IO0 | PF8 |
| OCTOSPIM_P1_IO1 | PF9 |
| OCTOSPIM_P1_IO2 | PE2 |
| OCTOSPIM_P1_IO3 | PF6 |

**System Core → RCC:** High Speed Clock (HSE) Crystal/Ceramic Resonator; Low Speed Clock (LSE) Crystal — часы панели берутся с ПЛК, LSE на плате как резерв. USB clock: HSI48.

После правок: **Project Manager → Generate Code**. Свои правки только внутри `USER CODE BEGIN/END`.

## 5. Трассировка

- Шлейф JP1 как можно короче. 16 линий данных одной длины, рядом земля.
- FMC и RMII не вести параллельно длинным пакетом.
- PC0 = LCD_D12. Сброс PHY **не** сажать на PC0 (у ПЛК так сделано — здесь нельзя).
- PA4/PA5 = данные экрана, не Ethernet и не ЦАП.
- Корпус модуля крепить за монтажные отверстия, без кручения стекла.
- На время пайки и первого включения — антистатик: модуль боится ESD.

## 6. Порядок первого включения

1. Перемычки раздела 2.
2. Только земля и 5 В модуля, без шин — ток покоя в норме, нет нагрева.
3. Подключить шину, сброс, подсветку. Без сенсора.
4. Прошивка: сброс → заливка регистров LT7683 → заливка цветом 1024×600. Подсветка PG1 = 1.
5. Затем I2C GT9271: сброс с INT=1 → адрес `0x5D`, прочитать ID (должно быть 9271).
6. Ethernet и пакет HMI — после стабильной картинки.
