# Поэтапный план реализации системы HVAC для чистых помещений

## Описание архитектуры
Распределенная система управления климатом, где **Главный ПЛК** собирает данные с подконтроллеров (**Локомотивов**), к которым по локальной шине подключены различные модули ввода/вывода (**Вагоны**). Связь внутри сцепок и между Главным ПЛК и Локомотивами осуществляется по шине CAN. Сторонняя система дверей интегрируется по RS485. Верхний уровень (HMI) общается с Главным ПЛК по Ethernet.

## Этапы реализации:

### Этап 1: Базовый (Разработка локальной "Сцепки")
*   Настройка базовой архитектуры модуля ввода/вывода ("Вагона"): инициализация периферии (АЦП для аналогового модуля, GPIO для дискретного).
*   Настройка подконтроллера ("Локомотива"): архитектура сбора данных.
*   Разработка протокола связи внутри сцепки (CAN-шина): адресация, идентификация типов модулей, передача данных от Вагонов к Локомотиву.

### Этап 2: Транспортный (Удаленное обновление)
*   Написание универсального загрузчика (Custom CAN Bootloader) для возможности удаленной прошивки Вагонов и Локомотивов без физического доступа к платам.

### Этап 3: Системный (Глобальная сеть)
*   Базовая настройка Главного ПЛК.
*   Реализация глобальной CAN-шины (Главный ПЛК <-> Локомотивы) для агрегации данных со всех сцепок в центральный контроллер.
*   Интеграция сети дисплеев (Настройка хаба Displays и локальных панелей 4.3").

### Этап 4: Интеграционный (RS485 и Ethernet)
*   Настройка интерфейса RS485 на Главном ПЛК для интеграции с уже готовой системой управления дверьми (PLC Doors).
*   Настройка интерфейса Ethernet (вероятно, Modbus TCP) для связи Главного ПЛК с главным HMI.

### Этап 5: Прикладной (Логика HVAC)
*   Написание алгоритмов управления микроклиматом (ПИД-регуляторы, обработка аварий, поддержание давления и температуры) внутри Главного ПЛК на основе собранных данных.
