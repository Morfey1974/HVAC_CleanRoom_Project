# Спецификация аппаратной части Главного ПЛК (Main PLC)

В данной таблице собраны все необходимые аппаратные узлы, их назначение в рамках проекта чистых помещений (HVAC), а также базовые настройки для STM32CubeMX и рекомендации по трассировке.

| Узел / Интерфейс | Назначение в проекте HVAC | Настройка в STM32CubeMX | Аппаратные особенности (Трассировка/Схема) |
| :--- | :--- | :--- | :--- |
| **FDCAN (1-2 шт.)** | Связь с модулями Locomotive, Displays и Wagons (датчики). | Включить FDCAN. Nominal Prescaler под скорость сети (например, 160 для 50 кбит/с). Включить прерывания IT0 (RX_FIFO0). | Обязательны трансиверы (TJA1051, SN65HVD230) и терминальные резисторы 120 Ом по краям шины. Подключение только через термобарьеры (Spoke). |
| **Ethernet (RMII/MII)** | Хостинг веб-интерфейса, интеграция со SCADA, протокол Modbus TCP. | Включить ETH (RMII). Активировать LwIP (Middleware). Настроить статический IP или DHCP. | Нужен внешний PHY (LAN8720/DP83848), трансформатор с гальванической развязкой (Магнетикс) и разъем RJ45. Трассировка дифференциальными парами. |
| **UART / RS-485** | Управление частотниками (VFD), вентиляторами, чтение сторонних Modbus RTU датчиков. | Включить USART/UART. Режим Asynchronous. Настроить Baud Rate (обычно 9600 или 19200). | Требуется трансивер RS-485 (MAX485/MAX3485) с защитой TVS-диодами. Желательна опторазвязка для защиты от пробоев из шкафа. |
| **USB (FS/HS)** | Отладка, первоначальная конфигурация без сети, обновление прошивки (DFU). | Включить USB_OTG_FS в режиме Device_Only. Middleware: USB_DEVICE (Virtual Com Port). | Дифференциальная разводка линий D+/D-, микросхема защиты от статики (USBLC6-2SC6). |
| **Память (SPI/QSPI Flash)** | Хранение HTML/JS/CSS для веб-интерфейса, графиков трендов, архива логов. | Включить SPI (Full-Duplex Master) или QUADSPI. Активировать FatFS (Middleware) для работы с файловой системой. | Располагать максимально близко к микроконтроллеру. QSPI требует согласования длины дорожек. |
| **EEPROM / FRAM (I2C)** | Надежное хранение уставок, ПИД-коэффициентов, калибровок, ID модулей без износа флэш-памяти. | Включить I2C (I2C1/I2C2). Скорость Fast Mode (400 кГц). | Обязательны подтягивающие резисторы (Pull-Up) номиналом 4.7 кОм к питанию 3.3В на линиях SDA и SCL. |
| **RTC (Часы реального времени)** | Выполнение расписаний, фиксация точного времени логов температуры и аварий. | Включить RTC (Activate Clock Source, Activate Calendar). Настроить LSE (внешний кварц). | Вывод VBAT подключить к батарейке CR2032 через диод. Кварц 32.768 кГц располагать вплотную к MCU, изолировать полигоном GND. |
| **Дискретные I/O (GPIO)** | Выходы: включение сирены, общая авария. Входы: пожарная сигнализация, статус ИБП. | Настроить нужные пины как GPIO_Output и GPIO_Input. Задать метки (User Label). | Выходы управлять через реле или транзисторные ключи. Входы изолировать через оптроны (PC817) для защиты от 24В. |
