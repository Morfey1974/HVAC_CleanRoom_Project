Design File Folder:  Should include all files that will be uploaded to web as part of the TIPD design archive.  This should include everything someone would need to simulate and build the TI Design.

Please include:
	
1.)  TIPD###_DesignFile.zip   <--- .ZIP of the following 4 subfolders 	

	
2.)  "SCH and BOM" Subfolder:  BOM for TI Design
		a.)  BOM_revX_.XLS.  Please read Guidelines-AltiumSCH_Archive_and_BOM.ppt.
		b.)  TIPD###_SCH_revX.pdf  Please read Guidelines-AltiumSCH_Archive_and_BOM.ppt.
	

3.)  "PCB" SubFolder:  Should include all files required to create/build the PCB and a .PDF of the 			     schematic
		a.)  Altium_and_Gerbers_revX.zip.  Please read Guidelines-AltiumSCH_Archive_and_BOM.ppt.    	  


	

4.)  "Simulation" SubFolder:  Should include all simulation files related to TI Precision Design.  Please 	     include short description in file names.
		a.)  .TSC files
			i.)  examples:  "Main_Simulation.TSC", "dc-Transfer.TSC", "Step-Response.TSC"
		b.)  .TDR files (optional)
		
	

5.)  "Other" Subfolder:  Anything else you would like the user/reader of the TI Precision Design to have
		a.)  Data
		b.)  Presentations (explaining stability or test methods)
		c.)  Appendix information
		d.)  etc.
