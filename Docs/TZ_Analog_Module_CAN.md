# Техническое задание: Разработка схемотехники системы сбора данных (Мастер-модуль + Модуль аналогового ввода) на шине CAN

## 1. Назначение и состав системы
Требуется разработка **только принципиальных электрических схем (Schematics)** для системы сбора данных. Трассировка печатных плат (PCB) на данном этапе **не требуется**.

**Протокол связи всей системы — CAN** (предпочтительно CAN 2.0B; допускается CAN-FD). Интерфейсы RS-485 и SPI для межмодульной и внешней связи в данном задании **не применяются**.

Система состоит из двух плат:
1. **Мастер-модуль («Локомотив»)** — шлюз: связь с головным PLC по CAN, раздача питания на измерительную часть, опрос модулей по внутренней CAN-шине сцепки.
2. **Модуль аналогового ввода («Вагон»)** — двухканальная плата оцифровки сигналов (0–10 В или 4–20 мА, например Rotronic HF5). Обмен с Мастер-модулем — только по CAN через разъём сцепки.

## 2. Требования к среде разработки и компонентам
*   **Среда разработки:** Строго **EasyEDA** (Pro или Standard).
*   **Компонентная база:** Все элементы с артикулами LCSC (C-part numbers) для PCBA / JLCPCB.

## 3. Архитектура и принципы построения
Ориентир: STM32 (например F103 / G0), АЦП (ADS1248 / ADS124S08), цифровые изоляторы (ISO7641), трансиверы CAN (TJA1051 / аналоги LCSC).

**Топология:**
*   **Головной PLC ↔ Мастер-модуль:** внешняя CAN-шина (на головном PLC — 1–2 CAN; несколько Мастеров на одной шине).
*   **Мастер ↔ модули:** внутренняя CAN-шина сцепки. Рекомендуется отдельный физический сегмент от внешней шины к PLC.

> [!IMPORTANT]
> Референс TI — только стандартный аналоговый вход (0–10 В / 4–20 мА). RTD и термопары **не требуются**.
> **Питание:** везде обычное (неизолированное) **24 В**; шина `+24V_ISO` не применяется. Допустимы ±15 VDC и иные шины на сцепке — по схеме Разработчика.
> Грамотная адаптация референса TI под наши требования — хороший вариант.

> [!NOTE]
> Разработчик может предложить свои решения (питание, CAN), сохраняя точность, отказоустойчивость и цифровую развязку измерительного тракта — **без** требования изолировать питание 24 В.
> HSI без кварца допускается, если стабильно для CAN. На шинах — места под терминаторы 120 Ω.

## 4. Схемотехника Мастер-модуля
1.  **Внешний CAN к головному PLC** — схема узла уже разработана Заказчиком и включается в схему Мастер-модуля (встраивание готового узла).
2.  **Питание:** внешние **обычные 24 В** раздаются на межмодульную шину **повсеместно**, без гальванической изоляции шины питания и без `+24V_ISO`. Защита линии (PTC, TVS) рекомендуется. Дополнительно по схеме Разработчика — логика и/или ±15 В DC.
3.  **Внутренний CAN сцепки** — схема узла уже разработана Заказчиком и включается в схемы обеих сторон сцепки; на разъёме `CAN_H` / `CAN_L`.
4.  **Адрес/слот** — схема адресации разрабатывается Заказчиком и включается в схемы; Разработчик только встраивает готовое решение.

## 5. Схемотехника Модуля аналогового ввода
1.  Питание с сцепки: обычные **24 В** (+ при необходимости ±15 В / логика по схеме Разработчика). Напряжения узлов определяет Разработчик (LDO / DC-DC по необходимости).
2.  Узел CAN — схема Заказчика включается в схему Модуля (без SPI к Мастеру).
3.  Клеммник: `+24В`, `GND`, `OUT1`, `OUT2`; обычные 24 В транзитом.
4.  Два канала 0–10 В / 4–20 мА с независимой конфигурацией.
5.  Цифровая изоляция **после** АЦП; аналоговые изоляторы до АЦП запрещены.
6.  Защита входов (перенапряжение, ESD, ЭМР, ошибочная подача 24 В).

## 6. Ожидаемый результат (Этап 1)
Схемы EasyEDA Мастер + Модуль AI, полный BOM LCSC, явно показанные узлы CAN (готовые узлы Заказчика встроены).

## 7. Дальнейшее сотрудничество (Этап 2: Трассировка PCB)
После успешного этапа схем — оплачиваемый PCB Layout. Габариты и распиновка CAN на сцепке — от Заказчика перед этапом 2.
